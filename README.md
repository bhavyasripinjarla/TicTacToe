# Tic-Tac-Toe

A simple two-player Tic-Tac-Toe game built with HTML, CSS, and JavaScript.

## Features

- Two-player gameplay using `O` and `X`
- Winner detection for all rows, columns, and diagonals
- Draw detection when all nine squares are filled
- Reset and New Game buttons
- Responsive board layout
- Centered winner and draw messages

## How to Run

1. Download or clone this repository.
2. Open the `tictactoe/index.html` file in a web browser.

You can also use the **Live Server** extension in VS Code and open `index.html` with Live Server.

## How to Play

1. Player `O` starts the game.
2. Players take turns selecting an empty square.
3. The first player to place three matching symbols in a row, column, or diagonal wins.
4. If all squares are filled without a winner, the match is a draw.
5. Select **Reset** or **New Game** to play again.

## Project Files

- `index.html` - Game structure
- `style.css` - Game styling and layout
- `app.js` - Game logic
